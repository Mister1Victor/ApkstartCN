Install Android to a virtual disk

The virtual machine window is open. Complete these six steps once. ApkStart will then boot directly from the disk without needing the image again.

  1. Boot menu：Use ↓ to select Installation - Install Android-x86 to harddisk，and press Enter
  2. Choose Partition：Select Create/Modify partitions；询问是否使Use GPT 时Select No
  3. cfdisk Partition：New → Primary → 容量直接and press Enter → Bootable → Write → 输入 yes → Quit
  4. Format：Select vda1 → 提示Format时Select ext4 → Yes
  5. Bootloader & system：Install GRUB Select Yes；Install /system as read-write Select Yes
  6. Done：进度到 100% 后点下面的「我已安装Done」（ApkStart 会Auto重启并接管）

If adb is not connected afterward: in the VM window, press Ctrl+Alt+F1 to open the terminal and run setprop service.adb.tcp.port 5555、stop adbd、start adbd， Then press Ctrl+Alt+F7 to return to the graphical interface.
