Install Android to a virtual disk

The virtual machine window is open. Complete these six steps once. ApkStart will then boot directly from the disk without needing the image again.

  1. Boot menu：用 ↓ select Installation - Install Android-x86 to harddisk，回车
  2. Choose Partition：选 Create/Modify partitions；询问是否使用 GPT 时选 No
  3. cfdisk 分区：New → Primary → 容量直接回车 → Bootable → Write → 输入 yes → Quit
  4. Format：选 vda1 → 提示格式化时选 ext4 → Yes
  5. Bootloader & system：Install GRUB 选 Yes；Install /system as read-write 选 Yes
  6. Done：进度到 100% 后点下面的「我已安装完成」（ApkStart 会自动重启并接管）

如果之后提示 adb 未连接：在虚拟机窗口按 Ctrl+Alt+F1 进入终端，执行 setprop service.adb.tcp.port 5555、stop adbd、start adbd， 再按 Ctrl+Alt+F7 回到图形界面。

Memory, CPU cores, rendering backend, ports, and acceleration are selected automatically. If startup fails, ApkStart retries with fallback settings.

The system image is shared by all apps, while app data is stored in separate layers. Old images, snapshots, logs, and lock files can be reclaimed. Logs rotate automatically. “Reset Android data” permanently deletes several GB of user data while keeping the system image.
Diagnostic reports help troubleshoot issues. Rebuild restores Desktop and Start menu shortcuts.
Start with Windows and stay in the system tray. Double-click a desktop shortcut to launch an app without starting ApkStart manually.
App window
随时按 F11 或右键托盘切换；全屏只放大窗口，不改变画面比例，切换不重启应用。
In windowed mode, drag the borders to resize freely. This controls Android’s internal rendering resolution; lower values use fewer resources.
Mouse controls
The emulator treats the left button as a finger tap; click and drag to swipe. No extra setup is needed.
By default, the emulator treats right-click as a tap (easy to trigger accidentally). Enable this to make right-click perform Back only.
Smooth mode combines wheel events over a short interval into one swipe, avoiding choppy scrolling and repeated adb process launches.
Side-button mapping uses a global mouse hook. It is active only while an ApkStart app window is focused and is removed immediately when focus is lost or the window closes.
These mappings apply only while an app window is focused. Mouse behavior returns to normal Windows behavior when you switch to the desktop or close the window.
Performance & Resource Usage
Controls Android VM CPU usage and visual quality. Choose “Performance” for demanding apps, or “Power saving” for lightweight background apps. Changes take effect the next time you open an app.
Expansion is performed in place. Installed apps and saves are preserved; the next launch may take a few extra seconds.

Assign public DNS servers (Alibaba / Tencent) to Android. By default, Android uses the host DNS, which can be slow when using a VPN or corporate network. Turn this off if internal domains stop resolving.

Container details (advanced)
Reduce the vCPU quota and process priority so Windows gets CPU time first. The Resource profile above configures this automatically.
When no app windows are open, the container automatically drops to the lowest priority.
Disable background packages such as Play Store, Setup Wizard, and print services, keeping only what apps need. If an app reports missing Google Play services, turn this off to restore them.
After ApkStart starts, Android is booted in the background with its window hidden. Apps then launch almost instantly instead of taking 20+ seconds. The trade-off is about 1 GB of idle memory usage; when disabled, the first app launch requires a cold boot.
Android boots once and stays running. Launching an app starts only that app rather than rebooting the system. Closing the last window cleans up background processes and parks the container.
Download & Update Sources
Auto checks GitHub and Gitee for the latest version, downloads 256 KB from each candidate URL to measure speed, then uses the fastest. An unavailable source will not block an update.
If GitHub is slow, also test the public ghfast.top and gh-proxy.com proxies (public release files only; no account access). When disabled, only direct connections and your custom prefix are used.
If set, only your prefix is used instead of the two public mirrors above. Leave blank to let Auto decide. The downloader prepends it to the original URL.
Large files are downloaded in parallel chunks. Eight threads are sufficient for most home connections; try 16 on a stable network.
